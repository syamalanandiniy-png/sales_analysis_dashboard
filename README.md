# 📊 Sales Analysis Dashboard

## 1. Project Overview
The Sales Analysis Dashboard is a data analysis project developed using Python, Oracle SQL, and Microsoft Excel. The main aim of this project is to analyze sales data, understand business performance, and identify useful sales insights through data analysis and visualization.

## 2. Objectives
- Analyze total sales revenue.
- Identify top-selling products.
- Understand monthly sales trends.
- Compare sales across different cities.
- Analyze product categories.
- Present sales insights using an Excel dashboard.

## 3. Technologies Used
- **Python:** Used for data analysis and calculations.
- **Oracle SQL:** Used to store, retrieve, and analyze sales data.
- **Microsoft Excel:** Used to create Pivot Tables, charts, and dashboards.
- **CSV:** Used to store the sales dataset.

## 4. Dataset Description
The project uses a sales dataset containing the following columns:

| Column Name | Description |
|---|---|
| Order_ID | Unique order number |
| Date | Date of purchase |
| Product | Product name |
| Category | Product category |
| City | Sales location |
| Quantity | Number of items sold |
| Price | Price per item |
| Revenue | Total sales amount |
| Month | Month of sale |

## 5. Project Files

1. **sales_analysis.py** – Python code for sales data analysis.
2. **sales_analysis.sql** – SQL queries for sales analysis using Oracle.
3. **sales_data.csv** – Dataset containing sales records.
4. **sales_dashboard.xlsx** – Excel dashboard with charts and Pivot Tables.
5. **README.md** – Project documentation and details.

## 6. Key Analysis
The project focuses on:
- Total Revenue Analysis
- Monthly Sales Analysis
- City-wise Sales Analysis
- Product-wise Sales Analysis
- Category-wise Sales Analysis
- Top-selling Products

## 7. Project Workflow
1. Collected the sales dataset in CSV format.
2. Analyzed and processed the data using Python.
3. Stored and queried sales records using Oracle SQL.
4. Created Pivot Tables and charts in Microsoft Excel.
5. Designed a dashboard to display important sales insights.

## 8. Dashboard
The Excel dashboard provides a visual representation of sales performance through charts, summaries, and sales comparisons.

## 9. Project Outcome
This project helped in understanding data analysis, SQL queries, data visualization, and dashboard creation. It also provides useful insights into sales performance and business trends.

## 10. Conclusion
The Sales Analysis Dashboard demonstrates how Python, Oracle SQL, and Microsoft Excel can be used together to analyze sales data and present meaningful business insights in a simple and professional way.
